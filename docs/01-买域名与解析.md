# 01 · 买域名与配置解析

## 一、在哪里买

**域名注册商**（卖域名的）和**服务器厂商**（租机器的）是**两件事**，
可以在不同平台，互不影响。

这次的情况：

| 东西 | 在哪买 |
| --- | --- |
| 域名 `laoma-apples.site` | 腾讯云 |
| 服务器 | 阿里云 |

**跨平台完全没问题**——只要在 DNS 里把域名指向服务器 IP 就行。

### 常见注册商

| 平台 | 注册入口 | 域名管理 |
| --- | --- | --- |
| 腾讯云 | <https://buy.cloud.tencent.com/domain> | <https://console.cloud.tencent.com/domain/all-domain/all> |
| 阿里云（万网） | <https://wanwang.aliyun.com/> | <https://home.console.aliyun.com/> → 域名 |
| 国外（界面英文） | Namesilo、Cloudflare Registrar | — |

> 本项目域名在**腾讯云**注册：买完后到
> [域名管理](https://console.cloud.tencent.com/domain/all-domain/all)
> 可以看实名状态、续费、改 DNS 服务器。

### 选域名的建议

| 后缀 | 说明 |
| --- | --- |
| `.com` | 最正式、长辈最认，做门面首选 |
| `.top` / `.xyz` | 首年常便宜，但**续费可能跳价**，下单前看清续费价 |
| `.cn` | 国内认，但注册要实名认证 |
| `.site` | 能用，但个别手机浏览器会把它当搜索词，需手动补 `https://` |

> ⚠️ **一定看清「续费价」**。首年便宜、续费翻几倍是行业常态。
> 域名一年几十元，直接开**自动续费**最省心——忘了续费网站就挂了。

名字要好念、好记，**能让果园老板念给顾客听**。不必追求短。

## 二、买完必须做实名认证

国内注册商都要求实名认证，**不认证会被暂停解析**。

腾讯云域名买完后，进入
[**域名注册控制台**](https://console.cloud.tencent.com/domain/all-domain/all)
→ 我的域名 → 点域名 → 实名认证，
按提示上传身份证、人脸核验，通常几小时到一天通过。

- 状态显示「**已实名认证**」才算完成
- 认证期间域名可以解析，但别拖太久

## 三、配置解析（关键步骤）

### 先搞清楚：解析由谁负责

域名的 **NS 记录**决定解析由哪家 DNS 服务商提供。腾讯云买的域名，
**默认 NS 指向 DNSPod，这是随域名免费的，够用**。

查一下当前的 NS：

```bash
dig +short NS laoma-apples.site
```

如果输出是 `*.dnspod.net`，说明解析在 DNSPod——**不需要额外买任何解析套餐**。

### 加两条 A 记录

打开 DNSPod 记录管理页：

- **本站的页面**（直接可用）：
  <https://console.dnspod.cn/dns/laoma-apples.site/record>
- **换成你自己的域名**：
  `https://console.dnspod.cn/dns/<你的域名>/record`
- **或从域名列表进**：<https://console.dnspod.cn/dns/list>
  → 点域名 → 记录管理

点「添加记录」，加**两条**，都指向服务器公网 IP：

| 类型 | 主机记录 | 记录值 | 说明 |
| --- | --- | --- | --- |
| A | `@` | 服务器公网 IP | 根域名，如 `laoma-apples.site` |
| A | `www` | 同一 IP | 让 `www.` 也能访问 |

**字段说明：**

- **主机记录**：`@` 代表域名本身，`www` 代表 `www.` 子域名。
  ⚠️ 填 `www` 而不是 `www.laoma-apples.site`——系统会自动补后缀，
  填全了会变成 `www.laoma-apples.site.laoma-apples.site`，永远不生效。
- **记录值**：服务器 **公网 IP**（在服务器厂商控制台的实例详情页看）
- 线路类型 / TTL：保持默认

### 删除冲突的记录

**A 记录和 CNAME 记录不能共存**。如果同一个主机记录下已有 CNAME
（比如之前绑过 EdgeOne、Vercel 之类），**先删掉再加 A 记录**。

### 验证解析是否生效

```bash
dig +short A laoma-apples.site
# 应输出你的服务器 IP

# 直连权威服务器查（绕过缓存，最快确认）
dig +short A laoma-apples.site @marble.dnspod.net
```

在线工具也行：<https://tool.chinaz.com/dns/>

生效通常几分钟；DNSPod 一般 1–2 分钟。偶有某台 DNS 服务器同步慢，
不影响使用。

## 四、常见误区

### ❌ 在 DNS 服务商控制台「绑定域名」就等于配好解析了

**不是。** 绑定只是平台内部的关联关系，**不改变 NS**，因此不会影响实际解析。
要让某家 DNS 服务商真正接管解析，必须去**域名注册商那里修改 NS 服务器**
（腾讯云：<https://console.cloud.tencent.com/domain/all-domain/all>）。

这次就踩了这个坑：在阿里云云解析 DNS 里绑定了域名、以为配好了，
实际 NS 还指向 DNSPod，所以那些配置一条都没生效。

### ❌ 以为需要买 DNS 解析套餐

**不需要。** 国内注册商都随域名免费提供基础解析（腾讯云是 DNSPod，
阿里云是云解析免费版）。个人站点、几条记录，免费版完全够用。

付费套餐的价值在于：更高解析量、更细的线路调度、更快生效时间（TTL 可设更短）、
更多记录条数。**这个项目一样都用不到。**

### ❌ 随便找个免费域名

免费子域名（如 `xxx.edgeone.dev`）**无法备案**，因此无法指向中国大陆服务器。
想用大陆节点就必须有自己的域名。详见 [03-edgeone-为什么放弃.md](03-edgeone-为什么放弃.md)。

## 五、备案：什么时候需要

| 情况 | 需要备案吗 |
| --- | --- |
| 服务器在**中国大陆** | ✅ **必须** |
| 服务器在**香港 / 境外** | ❌ 不需要（本项目即此情况） |
| 用大陆 CDN 节点 | ✅ 必须 |

**备案是法规要求，不是平台政策**：任何指向中国大陆服务器的域名都必须完成
ICP 备案（官方查询入口：<https://beian.miit.gov.cn/>）。备案要求你拥有可备案的域名，所以**免费子域名 + 大陆节点这条路不存在**。

备案流程通常 1–3 周，需要：实名域名 + 主体信息 + 大陆服务器或接入商。

**本项目选了香港服务器，因此完全跳过备案。** 代价是延迟比大陆节点高
（实测约 30–60ms，仍远好于境外 CDN 的 200ms 左右）。
