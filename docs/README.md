# 老马苹果园 · 上线全流程记录

这份文档记录**从零到网站可访问**的完整过程，包括走过的弯路和花过的钱。
写给以后接手的人（包括未来的自己）。

**最终结果**：<https://laoma-apples.site/> —— 阿里云香港节点，免备案，两个域名
（新站 + 原有项目）共用一台服务器。

---

## 一、先说结论：一条最短路径

如果重来一次，只需这四步：

| 步骤 | 在哪做 | 花费 |
| --- | --- | --- |
| 1. 买域名 | 腾讯云 | 约几十元/年 |
| 2. 域名实名认证 | 腾讯云（买完自动引导） | 0 |
| 3. 服务器放行 80/443 | 阿里云轻量应用服务器 | 0 |
| 4. DNSPod 加两条 A 记录 | DNSPod（腾讯云，随域名免费） | 0 |
| 5. 克隆项目并跑初始化脚本 | 服务器 | 0 |
| 6. 申请 HTTPS 证书 | 服务器（脚本自动） | 0（Let's Encrypt） |

**不需要买的东西**：DNS 解析套餐、SSL 证书、CDN、备案服务。

## 二、这次实际是怎么走的（含弯路）

```
买域名 laoma-apples.site（腾讯云）
        ↓
先试 EdgeOne Pages 免费托管 —— 失败（大陆访问 401）
        ↓
才发现服务器上早就有一台阿里云香港轻量服务器（跑着另一个项目）
        ↓
把新站部署到这台服务器上，与现有项目共存
        ↓
成功上线
```

弯路主要在 EdgeOne，详见 [03-edgeone-为什么放弃.md](03-edgeone-为什么放弃.md)。
**那一段不是白走**——它逼出了今天这套可用方案，经验也记在文档里了。

## 三、费用清单（真实数字）

| 项目 | 平台 | 费用 | 有用吗 |
| --- | --- | --- | --- |
| 域名 `laoma-apples.site` | 腾讯云 | 约几十元/年 | ✅ 必需 |
| DNS 解析套餐 | 阿里云 | **19.9 元** | ❌ **没用上** |
| 域名 `mizunoamitiger.me`（原有） | 阿里云 | 已有 | ✅ 在用 |
| 香港轻量服务器（原有） | 阿里云 | 已有 | ✅ 在用 |
| HTTPS 证书 | Let's Encrypt | 0 | ✅ 在用，自动续期 |

### 那 19.9 元的 DNS 解析套餐：白花了

**结论：对这个项目没有任何作用。**

原因：

1. 域名在**腾讯云**注册，DNSPod 是**随域名免费附带**的，解析本来就够用
2. 阿里云的解析套餐要用上，必须把域名的 **NS 服务器**改成阿里云的地址
   （形如 `vip3.alidns.com`），**这一步没做**
3. 在阿里云控制台点「绑定域名」只是平台内部的关联，**不会改变解析由谁负责**

实际验证（任何时候都可以自己查）：

```bash
dig +short NS laoma-apples.site
# 输出：parrot.dnspod.net. / marble.dnspod.net.
#       两个都属于 DNSPod，与阿里云套餐无关
```

**这笔钱能退吗**：可以试试在阿里云提交工单申请退款，套餐没用过（没改 NS、
没产生解析量）。但金额不大，为了它花时间也不一定值。

**留着有用吗**：有潜在价值——如果你以后想把域名管理统一到阿里云（服务器也
在阿里云），可以把 NS 改过去用上它。但**没必要专门为此折腾**，DNSPod 完全够用。

## 四、最终架构

```
用户浏览器
    ↓ https://laoma-apples.site
    ↓ https://mizunoamitiger.me      （原有项目，不受影响）
阿里云香港轻量服务器  47.239.154.107    （免备案）
    ↓
Docker: nginx:alpine 容器（占用宿主 80/443）
    ├─ server_name laoma-apples.site  →  /usr/share/nginx/laoma-apples
    │                                      ↑ 挂载自宿主机
    │                                      /home/admin/mizuno-ami-tiger/laoma-apples
    ├─ server_name mizunoamitiger.me  →  backend:8000 / frontend:80（原有项目）
    └─ server_name _（通配，只做 301 跳转）
```

**两个站点靠 `server_name` 区分，共用一套 Nginx 和端口。**
