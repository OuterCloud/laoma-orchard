## 与 `src/assets/` 的关系

这里的文件**不是网站直接用的图**。网站用的是处理后的产物：

```
originals/微信图片_*.jpg          ← 本目录（1279×1706）
        ↓ pnpm photos
src/assets/photos/*.jpg           ← 调色 + 降采样（1150×1438）
src/assets/crops/*.jpg            ← 首屏预裁图
        ↓ pnpm build
dist/_astro/*.{avif,webp,jpg}     ← 各档响应式尺寸（不进仓库）
```

处理是**不可逆**的：自动色阶、对比度 ×1.13、饱和度 ×1.16、亮度 ×1.06、
暗部抬升、锐化、暖冷微调，再降采样。所以原图需保留，供重新处理。

## 怎么用

```bash
pnpm photos    # 跑整条管线：originals/ → src/assets/
pnpm hero      # 只重做首屏裁切
pnpm qr        # 只重做二维码
```

**换照片**：新文件放进本目录，并同步更新

- `tools/photos.json` —— 照片清单（slug → 源文件名）
- `src/data/hero.json` —— 首屏用哪张、取景位置

**换二维码**：新图命名为 `微信二维码.jpg` 放进来，然后 `pnpm qr`。

## 注意

- **不要**把本目录放进 `src/`。Astro 只处理 `src/` 下的图片，放进去会被当作构建输入、产出无用变体。
- 调色参数在 `tools/process_images.py` 的 `GRADE` 里，注释写明「参数是逐张核对出来的，改动前请重新核对整组照片」。
