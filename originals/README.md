# 原始照片归档

老马果园的**原始照片**，未经任何处理。共 17 个文件、约 5.1 MB。

## 为什么放在这里

这批照片原先在 `~/Downloads/老马苹果园/`。那个位置有两个问题：

1. **Downloads 容易被随手清理**，而 `src/assets/` 里是**处理后的版本**
   （调色 + 锐化 + 降采样到 1150×1438），一旦原图丢失就**无法重新处理**
2. 换电脑或别人接手项目时，`~/Downloads/` 下不会有这些文件，
   `pnpm photos` 会直接报错

移进仓库后，源图随项目走，任何环境下 clone 下来就能重跑整条图片管线。

## 与 `src/assets/` 的关系

**这里的文件不是网站直接用的图。** 网站用的是 `tools/process_images.py`
处理后的产物：

```
originals/微信图片_*.jpg          ← 本目录（原始，1279×1706）
        ↓ tools/process_images.py
src/assets/photos/*.jpg           ← 调色 + 降采样（1150×1438）
src/assets/crops/*.jpg            ← 首屏预裁图
        ↓ astro build
dist/_astro/*.{avif,webp,jpg}     ← 各档响应式尺寸（不进仓库）
```

处理流程是**不可逆**的：自动色阶、对比度 ×1.13、饱和度 ×1.16、亮度 ×1.06、
暗部抬升、锐化、暖冷微调，然后降采样。所以**原图必须保留**——
想调整调色参数、重新裁图、或出一张更大的首屏图，都要从这里重新跑。

## 怎么用

```bash
pnpm photos    # 跑整条管线：originals/ → src/assets/
pnpm hero      # 只重做首屏裁切
pnpm qr        # 只重做二维码
```

换了照片或二维码，把新文件放进本目录，并同步更新：

- `tools/photos.json` —— 照片清单（slug → 源文件名）
- `src/data/hero.json` —— 首屏用哪张、取景位置

## 注意

- **不要**把本目录放进 `src/`。Astro 只处理 `src/` 下的图片，
  放进去会被当作构建输入、产出无用的变体。
- 调色参数在 `tools/process_images.py` 的 `GRADE` 里，
  注释写明「参数是逐张核对出来的，改动前请重新核对整组照片」。
